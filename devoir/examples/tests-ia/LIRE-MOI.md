# Fichiers fictifs pour tester Pacte

Tous les documents sont inventés et sans valeur contractuelle. Aucune analyse n’est attendue comme expertise juridique.

## Comment les utiliser

1. Ouvrir http://127.0.0.1:8082 et choisir Analyse IA.
2. Sélectionner un contrat de démonstration auquel associer le test. Pour un PDF, le document sera enregistré sur cette fiche : choisir une fiche de test.
3. Pour un TXT, utiliser « Importer un fichier texte (.txt) ».
4. Pour un PDF normal, utiliser « Importer un contrat PDF », puis « Utiliser le texte pour l’IA » si nécessaire.
5. Pour 04-internet-scan-ocr.pdf, importer le PDF puis choisir « Reconnaître le texte (OCR) ». Relire le texte reconnu avant l’analyse.
6. Cliquer sur « Analyser avec l’IA » et attendre la réponse. Le CPU peut nécessiter plusieurs minutes.
7. Valider et enregistrer uniquement si vous souhaitez conserver la fiche de test.

## Vérifications attendues

| Fichier | Points à vérifier dans le résultat |
| --- | --- |
| 01-internet-clauses-completes (.txt ou .pdf) | Durée du 1 janvier au 31 décembre 2027 ; renouvellement automatique de douze mois ; préavis de 30 jours ; pénalité de 10000 Ar par journée avec plafond mensuel ; règlement amiable puis médiation. |
| 02-maintenance-informations-manquantes (.txt ou .pdf) | Début au 1 février 2027 ; date de fin non renseignée ; modalités de renouvellement, préavis, pénalités et litiges à compléter. Ne pas inventer de délai, de date ou de clause. |
| 03-fournitures-contradictions (.txt ou .pdf) | Contradictions sur le renouvellement (articles 4 et 9), le préavis (30 ou 60 jours) et la livraison (15 mars ou 30 avril). Signaler les contradictions sans choisir arbitrairement une version. |
| 04-internet-scan-ocr.pdf | Aucun texte extractible avant OCR ; texte reconnaissable après OCR ; mêmes éléments essentiels que 01. |

Les cinq catégories doivent apparaître exactement une fois dans chaque fiche. Les citations doivent être présentes dans le texte chargé. Le résumé et les recommandations peuvent varier ; le niveau de risque n’est pas une réponse exacte imposée. Une analyse acceptée techniquement peut encore manquer un élément : comparer avec le tableau.
